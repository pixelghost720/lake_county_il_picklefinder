# Lake County IL Picklefinder
This is a pickleball court locator for Lake County, Illinois.

## Background
I noticed the poopular online sites were glaringly inaccurate, so I decided to make one myself and populate the data manually to ensure quiality. This information is sourced from calling local park districts, checking their websites, or driving around myself.

## Features
- Interactive map
- Filterable markers by court type
- Instant Google Maps directions

## Getting Started
Open https://pixelghost720.github.io/lake_county_il_picklefinder/ in your browser.
